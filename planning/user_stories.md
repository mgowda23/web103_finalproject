# User Stories

Reference the Writing User Stories final project guide in the course portal for more information about how to complete each of the sections below.

## Outline User Roles

Productive Professional: A user focused on organizing daily routines, tracking core habits, and maintaining streaks.

Lifelong Learner: A user tracking personal development goals, learning milestones, and category-tagged tasks.

## Draft User Stories

Here are 10 ready-to-use user stories tailored for your app:

1. As a Productive Professional, I want to create a new daily habit so I can track my morning routine.

2. As a Productive Professional, I want to view all my active tasks and habits in a clean dashboard view.

3. As a Productive Professional, I want to update the status of a task from incomplete to complete with a single click.

4. As a Productive Professional, I want to delete outdated tasks or habits that I no longer want to track.

5. As a Lifelong Learner, I want to assign custom category tags to my study goals so I can keep my personal development organized.

6. As a Lifelong Learner, I want to filter my tasks by category so I can focus exclusively on learning-related objectives.

7. As a Productive Professional, I want the app to validate my input when I create a task so I don't accidentally submit blank titles.

8. As a Productive Professional, I want to view AI-generated weekly insights summarizing my habit consistency and productivity bottlenecks.

9. As a Lifelong Learner, I want my habit streaks to update automatically when I log daily completions.

10. As a Productive Professional, I want the app to gracefully handle server errors with clear notifications if an update fails.
